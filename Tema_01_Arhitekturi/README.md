# Тема 1. Компютърни архитектури

Обхват: *Последователни и паралелни компютърни архитектури. Система от инструкции. Конвейерна обработка. Йерархия на паметта. Подсистема за вход/изход.*

Отвори `index.html` в браузър (или `dist/Tema_01_Arhitekturi.html`, същото в един файл).

Източник на съдържанието: „Тема 1 — Учебно ръководство“ (v1.1), „Разработка“, „Опорен план“ и „Речник на понятията“. Синият текст е маркиран като *разширение*.

## C кодът

Всички примери са в `c/`, по един файл на раздел, всеки с `main()`:

```
c/
├─ 01_bus.c        run_bus(): шина при фон Нойман / Харвард
├─ 02_cpu.c        alu8_add(), alu8_logic(), control() + cycle(): едноцикличен датапът RV32I
├─ 03_parallel.c   vec_add_sisd/simd(), round_robin()
├─ 04_isa.c        step(): интерпретатор на учебната ISA + assemble()
├─ 05_pipeline.c   pipeline(): 5-степенен конвейер с хазарти
├─ 06_cache.c      cache_access(), walk(), amat()
├─ 07_io.c         simulate(): polling / прекъсване / DMA
└─ 08_perf.c       cpu_time(), amdahl(), to_bytes() (ред на байтовете)
```

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/05_pipeline.c -o pipe && ./pipe
```

Визуализациите изпълняват същия алгоритъм в JS (`algos` на всеки раздел); подсветеният ред е редът, който се изпълнява в текущата стъпка. След промяна в `c/`: `python3 tools/gen_csrc.py Tema_01_Arhitekturi`.
