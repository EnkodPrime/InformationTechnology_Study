# InformationTechnology_Study

Интерактивни материали за подготовка за кандидат-докторантския изпит по докторска програма **„Информатика“** (професионално направление 4.6), Шуменски университет „Епископ Константин Преславски“.

Всяка тема от конспекта е в отделна папка. Във всяка има визуализации стъпка по стъпка, синхронизирани с примерен код на C/C++, редактируем вход и речник с подсказки по понятията.

## Как се отваря

Без инсталация и без сървър:

```
git clone https://github.com/EnkodPrime/InformationTechnology_Study.git
```

и отвори `index.html` (всички теми) или `Tema_05_Algoritmi/index.html` в браузър.

Алтернатива: `Tema_05_Algoritmi/dist/Tema_05_Algoritmi.html` е цялата тема в един файл — може да се копира и отвори където и да е.

## Структура

```
InformationTechnology_Study/
├─ index.html               списък на темите
├─ common/                  обща рамка (визуализатор, стилове, речник)
├─ tools/                   gen_csrc.py (C → визуализация), bundle.py (един файл)
├─ DEVGUIDE.md              как се добавя тема / визуализация
└─ Tema_05_Algoritmi/
   ├─ index.html
   ├─ c/                    всички C примери — компилират се самостоятелно
   ├─ js/                   по един файл на раздел
   ├─ tests/                сверка на визуализациите с реалния C изход
   └─ dist/                 еднофайлова версия
```
