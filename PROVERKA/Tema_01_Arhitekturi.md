# Тема 1. Компютърни архитектури
Обхват: 11 раздела (ch00–ch10), 8 C файла, 9 тестови файла, ~120 термина в речника. Първо прегледани 11-те незавършени промени от прекъснатата проверка (всичките запазени, една допълнително коригирана). Независими проверки: RV32I кодиране на 5-те инструкции, сверено с ръчно кодиране по формати R/I/S/B и с `llvm-mc -triple=riscv32 -show-encoding` (всички 5 съвпадат байт по байт); независим Python кеш-симулатор (LRU/FIFO, директно/по набори/напълно асоциативен), пуснат на presets и на 5-те конфигурации за обхождане на матрица (всички съвпадат с C/JS); ръчна проверка на C/V/Z/N (255+1, 127+1, 128+128, 200+100); формулите за конвейер (k+n−1, kn/(k+n−1)), трасиране на стойностите от 5-степенния модел (LOAD→ADD: 1 изчакване с препращане и 2 без); Амдал (f=0,9: p=4 → 3,0769, p→∞ → 10; f=0,8, p=4 → 2,5); T = IC·CPI/f (1 s / 1,25 s); AMAT (5 ns; две нива 2,5 ns); модела на шината (фон Нойман n+#LS; Харвард n или n+1); всички C файлове с -Werror и ASan+UBSan.

## Проверено и вярно (кратко)
- RV32I машинни кодове: ADD x3,x1,x2 = 0x002081B3; ADDI x5,x5,1 = 0x00128293; LW x5,4(x4) = 0x00422283; SW x5,4(x4) = 0x00522223; BEQ x1,x2,+16 = 0x00208863 — ръчно и с llvm-mc. Генераторът на imm (I/S/B, вкл. imm[12|10:5|4:1|11]) е верен; управляващите сигнали на 5-те инструкции съответстват на H&P (RISC-V edition, гл. 4.4).
- Флагове: C = пренос от MSB; V = c_in(MSB) ⊕ c_out(MSB); 255+1 → 0 C=1 V=0 Z=1; 127+1 → 128 C=0 V=1 N=1; 128+128 → 0 C=1 V=1. „RV32I няма регистър с флагове“ — вярно (Unpriv. ISA §2.4).
- „PC + 4 не е универсално — компресираните инструкции са 2 B“ — вярно (C разширение). x2 = SP по ABI — вярно (psABI).
- Конвейер: k+n−1, S = kn/(k+n−1) → k; 14 срещу 50; 7 срещу 15. LOAD-use: 1 мехурче с препращане, 2 без (запис/четене на регистровия файл в половин такт) — съответства на H&P.
- Кеш: offset = log2(линия), index = log2(набори), tag = останалото; 0/64 при 4×16 директно — 8/8 пропуска; 2-пътно — MMHHHHMM. Обхождане по редове/колони — всички 10 конфигурации съвпадат с независимата симулация.
- AMAT = t_hit + m·penalty = 5 ns; две нива 1 + 0,05·(10 + 0,2·100) = 2,5 ns.
- T = IC·CPI/f: 1 s и 1,25 s; Амдал 3,08 / 10 / 2,5.
- Шина: фон Нойман n + #(L,S), Харвард n или n+1 — съвпада с изхода на C.
- SIMD брой инструкции ⌊n/W⌋ + n mod W (n=10, W=4 → 4).
- Endianness 0x12345678 → big 12 34 56 78 / little 78 56 34 12.
- I/O модел: polling/IRQ/DMA — броячите в изхода са вътрешно последователни с описанието в коментара на модела.
