# Тема 3. Обектно ориентирано програмиране

Конспект: *Обектно ориентирано програмиране. Класове, обекти, полиморфизъм, наследяване, абстрактни класове, виртуални методи, предефиниране на операции, шаблони.*

Отвори `index.html` в браузър (без сървър) или самостоятелния `dist/Tema_03_OOP.html`.
Източник на съдържанието: Tema_03_Manual, Tema_03_Razrabotka, Tema_03_Oporn_plan, Tema_03_Ponyatia.

## Код

```
c/
├─ 01_model.cpp       ├─ 05_abstract.cpp
├─ 02_lifecycle.cpp   ├─ 06_operators.cpp
├─ 03_inheritance.cpp ├─ 07_templates.cpp
├─ 04_virtual.cpp     └─ 08_storage.cpp

```

```
g++ -std=c++17 -Wall -Wextra -Werror -O2 c/NN_x.cpp -o x && ./x
gcc -std=c11  -Wall -Wextra -Werror -O2 c/04_vtable.c -o v && ./v
```

Размерите, отместванията и vtable са измерени с g++ на x86-64 (Itanium C++ ABI) — не са езиков договор.
Матриците на достъпа (раздели 1 и 3) и таблицата на имената (раздел 4) се сверяват с това, което компилаторът
реално приема (SFINAE проверки в C++ кода).

## Проверка

```
sh tools/run_tests.sh Tema_03_OOP          # компилация с -Werror + сверка JS ↔ C++: 247 съвпадения, 0 разлики
python3 tools/clickall.py Tema_03_OOP      # 0 грешки във всички раздели
python3 tools/shot.py Tema_03_OOP <id> [--mobile --dark]
```

Всички 9 C/C++ файла минават чисто под `-fsanitize=address,undefined`.
Двойното освобождаване в `Shallow` (раздел 2) само се отбелязва в следата — програмата не изпълнява второто `delete[]`.
