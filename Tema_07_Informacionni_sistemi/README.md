# Тема 7. Информационни системи

Обхват: *Информационни системи. Класификация, проектиране и жизнен цикъл.*

Отвори `index.html` в браузър (или `dist/Tema_07_Informacionni_sistemi.html` — същото в един файл).

Темата е концептуална: акцентът е на щракаемите схеми и стъпковите симулации. C код има само там, където механизмът е реален.

## Раздели

```
Основа
├─ 0  Карта на темата                 4 въпроса (какво / как се класифицира / как живее / как се проектира), връзки
└─ 1  Същност и компоненти            схема 1 (хора, процедури, данни, техника; „само софтуер“),
                                      заявление през ИС с граница, схема 2 (данни → информация), качество на данните
Класификация
├─ 2  Управленско равнище             схема 3 (пирамида TPS/MIS/DSS/ESS), една продажба в 4 употреби,
│                                     схема 4 (независими оси: равнище, структурираност, организация)
├─ 3  Функция и организация           схема 5 (ERP/CRM/SCM/документи по пакети), обхват/организация/режим,
│                                     OLTP/OLAP, CRM → ERP: синтактична срещу семантична съвместимост
└─ 4  Управление на проекти и PMIS    дейност / организация / PMIS / Jira, схема 6 (T17: отчет → справка →
                                      решение → промяна; процедура и права), портал ≠ PMIS, Scrum/Kanban
Жизнен цикъл и проектиране
├─ 5  Жизнен цикъл                    схема 7 (кръг с обратна връзка), симулация на версии и пропуснати дейности
├─ 6  Изисквания и моделиране         проверими изисквания, NFR проверка (C), проследимост — анализ на
│                                     въздействието с BFS (C), схема 9 (случаи на употреба), схема 10 (DFD ниво 0/1)
├─ 7  Проектиране на решението        схеми 12–13 (слоеве ≠ машини), последното място: проверка-после-запис
│                                     срещу атомарно (C), схема 14 — идемпотентна повторна заявка (C)
├─ 8  Модели на разработване          схема 15 (каскаден/итеративен/инкрементен/спирален/гъвкав), цена на късната
│                                     промяна (учебен модел), спирала по риск, V&V, нива на проверка, схема 17
└─ 9  Единен пример и миграция        потребност → замяна, схеми 19–20: 5 проверки при миграция BGN → EUR (C),
                                      ETL/ELT, микросервиси
Обобщение
└─ 10 Систематизация и опорен план    TPS/MIS/DSS/ESS, 12 двойки разграничения, модели, изяснени въпроси,
                                      опорен опорен план, източници
```

## C кодът

```
c/
├─ 06_requirements.c   nfr_check (измеримо НФИ), impact (BFS по проследимостта)
├─ 07_design.c         enroll_step / run_schedule (състезание за място), server_handle / client_send (идемпотентност)
└─ 09_migration.c      bgn_to_eur, migrate (6 типични грешки), accept (5 проверки)
```

```
gcc -std=c11 -Wall -Wextra -O2 c/07_design.c -o design && ./design
```

Визуализациите изпълняват същата логика в JS и подсвечват реда, отбелязан с `//@етикет`.

## Проверка

```
sh tools/run_tests.sh Tema_07_Informacionni_sistemi       # компилира с -Werror и сверява JS ↔ C
python3 tools/clickall.py Tema_07_Informacionni_sistemi   # натиска всички бутони във всички раздели
```

Състояние: 3 C файла, 0 предупреждения, чисти под AddressSanitizer/UBSan;
73 сверки JS ↔ C + 19 проверки на концептуалните симулации — 0 разлики; clickall — 0 грешки.
