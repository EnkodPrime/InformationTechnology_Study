## C код

Всеки файл в `c/` е самостоятелен, с `main()` (в `#ifndef NO_MAIN`), който печата редове `име = стойност`:

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/08_rules.c -o 08 && ./08
gcc -std=c11 -Wall -Wextra -g -fsanitize=address,undefined c/08_rules.c -o 08s && ./08s
```

След промяна в `c/`: `python3 tools/gen_csrc.py Tema_08_Inteligentni_sistemi` (от корена на репото).
