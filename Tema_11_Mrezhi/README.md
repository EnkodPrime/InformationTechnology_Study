# Тема 11. Компютърни мрежи

Конспект: *Компютърни мрежи. Класификация, основни протоколи, интерфейси и услуги. Интернет.*

Отвори `index.html` в браузър (или `dist/Tema_11_Mrezhi.html` — същото в един файл).

## C кодът

Всички примери са в `c/` — по един файл на раздел (01–11), всеки с `main()`:

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/03_encap.c -o encap && ./encap
```

Визуализациите показват точно тези функции; подсветеният ред е този, който се изпълнява в текущата стъпка.
Байтовете на кадъра в раздел 3 са проверени независимо (контролните суми и CRC-32 спрямо zlib);
Modbus RTU заявката `01 03 00 00 00 01 84 0A` съвпада с примера от ръководството.
