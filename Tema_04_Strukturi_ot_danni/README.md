# Тема 4. Структури от данни

Обхват: *Абстрактни структури от данни. Стек, опашка, линеен списък, двоично дърво. Реализация и основни операции.*

Отвори `index.html` в браузър (или `dist/Tema_04_Strukturi_ot_danni.html` — същото в един файл).

## Раздели

```
Основа
├─ 0  Карта на темата                 4-те въпроса: договор / разположение / инвариант / цена при условие
└─ 1  АТД и реализация                една програма върху масивен и свързан стек едновременно (свои операции)
Линейни структури
├─ 2  Стек                            динамичен масив с удвояване и копиране, амортизация (m push),
│                                     проверка на скоби, постфиксен израз
├─ 3  Опашка                          стек срещу опашка, кръгов буфер head+size (отказ/презаписване),
│                                     вариант head/tail с празна клетка, свързана опашка, дек
└─ 4  Линеен свързан списък           кутии и стрелки: едносвързан и двусвързан кръгов със сентинел,
                                      pushf/pushb/find/ins/del, грешен ред на присвояванията
Дървета
├─ 5  Двоично дърво и обхождания      pre/in/post (стек на рекурсията), level-order (опашка), височина/дълбочина,
│                                     full/complete/perfect, представяне в масив, дърво за израз
└─ 6  Двоично дърво за търсене        ins/find/del/min/max, трите случая на изтриване, балансирано срещу изродено
Сравнение
└─ 7  Съпоставка на реализации        таблица на сложностите, броене на стъпки: масив / списък / BST
Разширение
└─ 8  Допълнение                      min-heap в масив, AVL ротации (LL/RR/LR/RL), red-black, B/B+, trie, хеш
Обобщение
└─ 9  Систематизация                  разграничения, изяснени въпроси, опорен план, реални примери, източници
```

Визуализаторите приемат програма от операции, напр. `push 3, push 5, pop`, `enq 4, deq`, `ins 7 5, del 4`, `ins 4 2 6 1 3, find 3, del 2`. Дърветата се задават по нива: `4 2 6 1 3`, `-` = липсващо дете.

## C кодът

Всички примери са в `c/` — по един файл на раздел (`01_adt.c` … `08_extra.c`), всеки с `main()`; `c/ops.h` е служебен разбор на текстовите програми от операции (същия формат като полетата във визуализаторите).

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/04_list.c -o list && ./list
```

Визуализациите показват точно тези функции; подсветеният ред е редът, който се изпълнява в текущата стъпка.
