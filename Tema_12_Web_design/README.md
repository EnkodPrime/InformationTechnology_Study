# Тема 12. Уеб дизайн

Обхват по конспекта: **Основни структурни елементи, форматиране и програмиране.**

Отвори `index.html` или самостоятелния `dist/Tema_12_Web_design.html`.

| Раздел | Материал и взаимодействие |
|---|---|
| 0 | Карта и разпределение на отговорностите HTML/CSS/JavaScript |
| 1 | HTML документ, семантика, DOM; playground за структурни елементи и редактор с изолиран преглед |
| 2 | CSS каскада и специфичност; стъпково изчисляване на кутиев модел |
| 3 | Playground с HTML, Flexbox, Grid и media queries: падащи менюта, числови контроли, готови примери и незабавен преглед |
| 4 | JavaScript, DOM и събития; стъпков брояч, работещ брояч и път на събитие |
| 5 | Формуляри, валидация, GET/POST и клиент–сървър; локална обработка на данни |
| 6 | Систематизация, опорен план, работен процес и първични източници |

Примерите са на HTML/CSS/JavaScript. Редакторите работят в sandbox iframe без изпълнение на скриптове; формулярът не изпраща данни към сървър. Fetch примерът е само показан код.

Проверки: `node Tema_12_Web_design/tests/models.test.js` от корена на проекта.

Playground модели: `node Tema_12_Web_design/tests/playground.models.test.cjs`.

Проверка в Chromium (изисква Playwright и инсталиран негов Chromium): `node Tema_12_Web_design/tests/playground.browser.test.cjs`. Проверява реалните CSS стойности, граничните ширини на media queries, контролите и тесен екран.

Playground-ът показва генерирания HTML и CSS и работи без JavaScript в sandbox прегледа. Промените на настройките се отразяват веднага. Превключването на структурен HTML елемент може да запази визуалния вид, затова има видими имена на таговете. Ширината на iframe е действителният viewport за media queries; при широк преглед на тесен екран се превърта само областта на прегледа.

Пакет: `python tools/bundle.py Tema_12_Web_design`.

Отделен playground: `playground.html`. Обновяване: `python tools/build_web_playground.py`.
