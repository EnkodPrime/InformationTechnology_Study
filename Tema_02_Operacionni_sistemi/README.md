# Тема 2. Операционни системи

Конспект: *Операционни системи. Състав и функции. Управление на паметта, процесите и ресурсите. Файлови системи.*

Отвори `index.html` в браузър (или `dist/Tema_02_Operacionni_sistemi.html` — същото в един файл).

## C кодът

Всички примери са в `c/` — по един файл на раздел (01–08), всеки с `main()`:

```
gcc -std=c11 -Wall -Wextra -O2 c/03_planirane.c -o planirane && ./planirane
```

`c/04_sinhronizacia.c` използва pthread (на Linux с glibc ≥ 2.34 не е нужен `-pthread`; на по-стари системи добави го).
Механизмите на ядрото (планировчик, MMU, файлова система) са учебни модели в потребителското пространство — същите
алгоритми, които визуализациите показват стъпка по стъпка; подсветеният ред е редът на текущата стъпка.

## Проверка

```
sh tools/run_tests.sh Tema_02_Operacionni_sistemi      # компилира с -Werror и сверява JS стъпките с C изхода
python3 tools/clickall.py Tema_02_Operacionni_sistemi  # натиска всички бутони във всички раздели
```

Състояние: 8 C файла, 0 предупреждения, чисти под AddressSanitizer/UBSan; 300 сверки JS↔C, 0 разлики;
clickall — 0 грешки; без хоризонтално препълване на 390 px.
