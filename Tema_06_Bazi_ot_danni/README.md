# Тема 6. Бази от данни

Конспект: *Бази от данни. Системи за управление на бази от данни, релационен модел, нормализация.*

Отвори `index.html` в браузър (или `dist/Tema_06_Bazi_ot_danni.html` — същото в един файл).

## C кодът

Алгоритмите са на C11 в `c/`, всеки файл с `main()`, който печата `име = стойност`:

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/05_fd.c -o fd && ./fd
```

```
c/
├─ 02_relmodel.c   ограничения при вмъкване и изтриване
├─ 03_algebra.c    σ π × ⋈ ∪ − ∩
├─ 04_sql.c        LEFT JOIN + WHERE + GROUP BY/COUNT, тризначна логика
├─ 05_fd.c         затваряне X⁺, кандидатни ключове, проверка на ФЗ в данни
├─ 06_nf.c         анализ на НФ, BCNF разлагане, запазване на ФЗ, chase, фалшиви кортежи (#include "05_fd.c")
└─ 09_tx.c         превод с undo log, разписание на две транзакции, индекс
```

SQL е показан само като текст до визуализациите.
