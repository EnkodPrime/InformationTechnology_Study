# Тема 5. Алгоритми

Обхват: *Алгоритми. Свойства, изчислимост, P и NP класове от задачи. Рекурсия, разделяй и владей, алчен подход, динамично програмиране.*

Отвори `index.html` в браузър (или `dist/Tema_05_Algoritmi.html` — същото в един файл).

## Раздели


## C кодът

Всички примери са в `c/` — по един файл на раздел, всеки с `main()`:

```
gcc -std=c11 -Wall -Wextra -O2 c/06_divide.c -o divide && ./divide
```

Визуализациите показват точно тези функции; подсветеният ред е редът, който се изпълнява в текущата стъпка.

```
sh tests/run_all.sh          # компилира всички C файлове с -Werror и сверява JS стъпките с C изхода
```
