# Тема 9. Компютърна сигурност

Обхват: *Компютърна сигурност. Мрежови атаки, социално инженерство.*

Отвори `index.html` в браузър (или `dist/Tema_09_Sigurnost.html` — същото в един файл).

Материалът е за **защита**: атаките са показани като модели в паметта и диаграми. В C кода няма мрежа и няма сокети — той е защитен или моделиращ.

## C кодът

```
c/01_access.c    check_access (ACL), risk_eval (матрица 5×5)
c/03_arp.c       модел на ARP кеш: arp_receive / arp_resolve, статичен запис, DAI
c/05_app.c       validate_name, bind_name (параметър), copy_checked, pw_bits, toy_hash (сол — концепция)
c/07_defense.c   fw_check (първото съвпадащо правило), ids_signature, ids_anomaly
```

```
gcc -std=c11 -Wall -Wextra -Werror -O2 c/07_defense.c -o fw -lm && ./fw
```
